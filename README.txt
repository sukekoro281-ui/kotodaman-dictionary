コトダマン辞書　複合ワード検索追加版（2026-11-10）

【更新内容】
・7マス盤面に対し、6マスまたは7マスで成立する「2語の重なり」を別枠で表示。
・対象：5文字＋5文字、5文字＋6文字、6文字＋5文字。
・固定文字を保持し、空欄部分を補って一致する2語を辞書から検索。
・6マス候補は左側1〜6マス、右側2〜7マスの両方を検索。
・候補ごとに、2語の内訳、共有文字数、使用位置、予想コンボ数を表示。
・「デッキで作れる語のみ」の絞り込みと、手札優先に対応。
・検索負荷対策として各配置で上位16件まで表示。さらに表示ボタンあり。
・2026-10-31の検索履歴追加・修正と今回の変更を更新履歴ページへ追記。

【適用方法】
1. 既存の index.html と update-history.html をバックアップ。
2. このZIPの index.html と update-history.html をGitHubリポジトリの同名ファイルに上書き。
3. GitHub Pagesへの反映を待ち、ページを再読み込み。
4. 7マスの盤面（例：○さい○○○い）を入力すると、通常検索結果の上に「複合ワード候補」が表示されます。

【変更していないもの】
・words-local.txt（統合辞書）
・public-decks.js（共有デッキ）
・Firebase設定、OCR連携

【注意】
・辞書に載っている2語を機械的に組み合わせる機能です。ゲーム内で実際に成立するかは未確認です。
・ウォールありの盤面では複合候補を表示しません（通常のウォール検索は従来どおり）。
・「デッキで作れる語のみ」をONにすると、現在のデッキで空欄を埋められる候補だけになります。
・ブラウザ実機・iPhoneでの操作検証は未実施。JavaScript構文と検索ロジックは検証済みです。
・本版は 2026-10-31 の検索履歴修正版をベースにしています。それ以降に独自の変更を加えた場合は、上書きせず差分を統合してください。
