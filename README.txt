コトダマン辞書　検索履歴10件＋複合ワード開閉版（2026-11-12）

【更新内容】
・最近の検索履歴を最大5件から最大10件に変更。
・保存済みの過去5件は同じ端末のブラウザ内でそのまま引き継ぎます。
・入力終了から10秒後の自動保存、重複除外、タップでの盤面復元、履歴削除は維持。
・複合ワード候補は7マス盤面で見出しのみを表示し、初期状態では閉じています。
・「複合ワード候補」をタップすると開閉でき、開いたときに候補を計算します。
・複合ワード検索の対象（5＋5、5＋6、6＋5、6〜7マス）は変更していません。
・update-history.htmlに今回の更新を追記。

【適用方法】
1. 現在の index.html と update-history.html をバックアップ。
2. ZIP内の index.html と update-history.html をGitHubの同名ファイルに上書き。
3. GitHub Pagesへの反映後、再読み込みして動作を確認。
4. 7マスの盤面を入力し、「複合ワード候補」をタップすると結果を展開できます。
