ゲーム向け辞書・報告語

従来の words-local.txt は既存の非公式ゲーム向け辞書です。いとうき・いこうき は検索の抜けを補う参考語として追加しました。

注意：JMdictの読みが日本語として正しくても、コトダマン内で成立するとは限りません。検索結果の「一般辞書・ゲーム内未確認」を参照してください。収録語数はゲーム内の正式登録語数ではありません。

更新頻度

GitHub Actionsで週1回、JMdictを再取得して差分のみ更新します。取得・検証に失敗した場合は以前のデータを維持します。
